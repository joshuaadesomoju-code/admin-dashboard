# Store Admin Dashboard

A React admin dashboard for an online store: revenue and order stats, a revenue chart, an inventory health chart, a searchable orders table and a restock list. Data is pulled live from the free [DummyJSON](https://dummyjson.com) API.

Built with React, Vite and Tailwind CSS. Charts are hand-built SVG with hover tooltips, keyboard focus and a table view.

## Run it locally
```bash
npm install
npm run dev
```
